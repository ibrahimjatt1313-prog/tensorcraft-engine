# TensorCraft AI SRE Engine 🚀

An enterprise-grade, autonomous Site Reliability Engineering (SRE) platform engineered for real-time incident diagnostics, intelligent root-cause analysis (RCA), and automated cloud reliability management.

---

## 🏛️ Architecture & Stage-Wise Repository Structure
This repository adheres strictly to the multi-stage validation architecture mandated by the Dark Factory framework:

* **`stage-1/`**: Core Backend Conformance API (`main.py`) – Handles telemetry ingestion, metrics aggregation, and core SRE business logic.
* **`stage-2/`**: Responsive Web Dashboard (`index.html`) – Real-time visualization interface built for operational monitoring and incident tracking.
* **`stage-3/`**: State Management & Service Logic (`App.tsx`) – Reactive frontend application state, live telemetry polling, and user interaction handlers.
* **`stage-4/`**: Domain Extension & Configuration (`requirements.txt`) – Dependency management, deployment hooks, and environmental orchestration.

---

## 🛠️ Technology Stack
* **Core Backend:** Python, RESTful Microservices Architecture
* **Frontend UI:** React, TypeScript, Tailwind CSS, Vite, Recharts
* **Telemetry & Automation:** Custom AI diagnostics engine for automated log analysis and alerting
* **Deployment & CI/CD:** Vercel, Git-based version control, and automated validation harness
