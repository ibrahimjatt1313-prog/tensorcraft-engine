## 🌐 Overview

**TensorCraft AI** is an advanced, enterprise-ready Site Reliability Engineering (SRE) command center built to minimize Mean Time to Resolution (MTTR). By blending real-time cluster telemetry, multimodal voice and gesture control, and autonomous AI-driven sandbox remediation, it empowers DevOps teams to diagnose and resolve cloud infrastructure failures dynamically.

---

## 🚀 Core Architecture & Features

* **🧠 Autonomous Self-Healing Engine:** Automatically detects critical anomalies (such as memory leaks in microservices) and triggers isolated sandbox patches to restore stability.
* **🎙️ Multimodal Control (Voice & Vision):** Hands-free operation utilizing Web Speech API triggers (e.g., *"fix the system"*) and computer vision stream integration.
* **📊 Real-Time Telemetry & Monitoring:** Live data feeds streaming CPU load, memory utilization, and network latency directly into dynamic Recharts graphs.
* **☸️ Kubernetes Pod Topology Inspector:** Deep-dive modal drawer displaying active pod instances across regions (`us-east-1`, `eu-central-1`, `ap-south-1`) with granular container restart controls.
* **📋 Enterprise Audit & Alerting:** Automated event logging, live diagnostic streams with auto-scrolling output, simulated Slack alerts, and JSON audit report generation.

---

## 🛠️ Technology Stack

* **Frontend Dashboard:** React, Vite, Tailwind CSS, Recharts, Lucide Icons
* **Backend Services:** Python, Flask, RESTful Endpoints, Multithreaded telemetry state
* **Infrastructure & Ops:** Kubernetes Multi-Cluster Simulation, Git version control, Vercel / Localhost hosting
